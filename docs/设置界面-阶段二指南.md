# 设置界面 · 阶段二指南：翻译档位 + 快捷键录制

> 本阶段目标：在设置窗口里切换「高速度 / 高质量」，以及用「录制」按钮直接按下新快捷键，
> 点保存后立刻生效；被占用的组合会被拦下来并保留原来的快捷键。

## 二、翻译档位怎么用

### 界面在哪

打开「设置…」窗口 → 中间那个叫 **「翻译档位」** 的区块。

```
┌ 翻译档位 ──────────────────────────────────────────┐
│  (•) 高速度   响应快，适合日常聊天、随手翻译          │
│  ( ) 高质量   更准确，适合邮件、文档等正式内容        │
│  当前档位实测响应：中译英约 0.03 秒/句，中译日约 0.09 秒/句。│
│  日常聊天建议用这一档。                              │
└────────────────────────────────────────────────────┘
```

### 两个档位到底差在哪（通俗版）

| | 高速度 | 高质量 |
|---|---|---|
| 一句话解释 | 引擎"想一遍就答"，够快够用 | 引擎"多想几种说法挑最好的" |
| 中→英 实测 | 约 0.03 秒/句 | 约 0.05 秒/句 |
| 中→日 实测 | 约 0.09 秒/句 | 约 0.11 秒/句 |
| 什么时候选它 | 微信聊天、随手记、看网页 | 写邮件、发文档、要给人看的内容 |

> 两个档位都很小（0.1 秒以内），日常用起来几乎感觉不到差别，
> 难分的时候**就用默认的「高速度」**。

### 操作步骤

1. 打开「设置…」→ 点 **「高质量」**
2. 下面那行说明文字会**立刻变成高质量档的实测数据**（这就是"说明当前档位的速度差异"）
3. 点 **「保存」** → 弹 `设置已保存并立即生效，无需重启软件。`
4. 随便找个输入框打中文按 `Alt+J`，已经是新档位在跑了

### 托盘也能改（两处保持同步）

右键托盘图标 → 「翻译档位」→ 选一个。

**预期**：如果设置窗口正开着且你没在里面改过东西，**窗口里的单选按钮会自动跟着变**，
不会出现"窗口显示高速度、实际跑高质量"的错乱。

> 如果窗口里正好有你**还没保存**的改动，窗口顶部会显示黄色提示条：
> `有未保存的修改。当前实际生效的是：… 。点「保存」后生效。`
> 这样你能一眼看清"我改的"和"正在生效的"分别是哪个。

## 三、快捷键怎么改

### 界面在哪

最下面那个 **「快捷键」** 区块：

```
┌ 快捷键 ────────────────────────────────────────────┐
│  按一下就能把刚打的中文变成译文。                     │
│  [ Alt+J            ]  [录制]  [恢复默认]            │
│  要求：至少包含一个 Ctrl / Alt / Shift，再加一个主键… │
└────────────────────────────────────────────────────┘
```

### 录制一个新快捷键

1. 点 **「录制」** 按钮
2. 输入框内容变成 `请按下快捷键…`，下面的提示变成
   `现在请直接按下你想用的组合键（例如按住 Alt 再按 J）。按 Esc 取消。`
3. **在键盘上直接按** 你要的组合，比如按住 `Ctrl` 和 `Alt` 再按 `J`
4. 输入框立刻显示 **`Ctrl+Alt+J`**，录制结束
5. 点 **「保存」**

**几个细节**：

- 只按修饰键（比如只按 Ctrl）**不算完成**，会提示你继续按主键
- 只按一个普通键（比如单独按 `J`）**会被拒绝**，提示"必须至少包含一个 Ctrl / Alt / Shift"
  （这是为了防止设成单键后干扰你正常打字）
- 中途不想录了，按 **`Esc`** 取消

### 恢复默认

点 **「恢复默认」** → 输入框回到 `Alt+J`（**还需要点「保存」才真正生效**）。

窗口底部的 **「恢复默认设置」** 按钮则是把**档位和快捷键一起**恢复默认，
会先弹确认框：`将把快捷键恢复为 Alt+J、翻译档位恢复为「高速度」。注意：这只会改回窗口里的值，点「保存」后才真正生效。`

### 保存后立即生效

保存成功后弹窗里会多一句提示：

> 提示：新快捷键已经生效。如果按下去没反应，说明这个组合被别的软件抢占了（这类冲突无法自动检测），换一个组合重新设置即可。

**不需要重启软件**，立刻就能用新快捷键。

## 四、快捷键被占用怎么办（重点）

程序做了**两层保护**：

### 第一层：自动探测（能查出来的直接拦下）

保存时程序会用 Windows 的 `RegisterHotKey` 试着注册一下这个组合。
如果被系统或其他软件**注册成全局热键**了，注册会失败，程序就会拦下来：

**你会看到**：

```
┌ 快捷键设置失败 ──────────────────────────────────┐
│ 无法使用「Ctrl+Alt+K」。                          │
│                                                   │
│ 这个组合已经被系统或其他软件注册为全局快捷键了。    │
│                                                   │
│ 已保留原来的快捷键「Alt+J」，你可以换一个组合再试。│
│                                        [确定]      │
└───────────────────────────────────────────────────┘
```

**关键点**：原来的快捷键**照样有效**，软件绝不会出现"新键没设上、旧键也丢了"的情况。

### 第二层：保存后的提醒（查不出来的，靠你换一个）

有些软件（输入法、截图工具、游戏）是用"键盘钩子"实现的快捷键，
这类占用**无法被自动检测**。所以保存成功后程序会提醒你：

> 如果按下去没反应，说明这个组合被别的软件抢占了，换一个组合重新设置即可。

**排查办法**：换个更复杂的组合，比如 `ctrl+shift+alt+t`，或者用 `F9`。
实在不行，运行 `0-自检.bat`，第 7 项会告诉你当前配置的快捷键能不能注册。

## 六、常见报错与解决

| 现象 | 原因 | 解决办法 |
|---|---|---|
| 录制时按了组合键，框里没反应 | 输入框失去了焦点（比如你先点了别的窗口） | 重新点「录制」再按 |
| 提示"必须至少包含一个 Ctrl / Alt / Shift" | 你只按了一个普通键 | 加上修饰键，如 `Ctrl+Alt+J` |
| 想用 Win 键组合但录不进去 | Windows 会把 Win 组合优先给系统，窗口内收不到 | 手工编辑 `config.json`，写 `"hotkey": "windows+j"` 后重启程序 |
| 保存报"该组合已被占用" | 探测到系统/其他程序已注册 | 换一个组合，原快捷键仍然有效 |
| 保存成功但按键没反应 | 被钩子类软件抢占（无法自动检测） | 换 `ctrl+shift+alt+` 开头的组合 |
| 保存后想反悔 | 配置已经写进去了 | 重新设为 `Alt+J` 再保存一次；或托盘菜单 → 打开配置文件手工改回 |
