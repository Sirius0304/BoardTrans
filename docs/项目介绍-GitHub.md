# 瞬译（ShunYi）

> 在任意软件里用中文打字，按一下 `Alt + J`，刚才那句话**原地变成英文或日文**。
> 完全离线，不联网，不需要 API Key。托盘常驻，可打包成单个 exe（34 MB，双击即用）。

| 项目 | 说明 |
|---|---|
| 平台 | Windows 10 / 11（64 位） |
| 翻译方向 | 中文 → 英文、中文 → 日文 |
| 引擎 | CTranslate2 + OPUS-MT 神经网络模型（本地 CPU 推理） |
| 速度 | 中→英 26 ms/句（高速档）/ 54 ms（高质量档） |
| 模型 | 186 MB（71 MB + 115 MB），只需下载一次 |

---

## 解决什么问题

跨语言写作的常规流程是「切到翻译软件 → 复制 → 粘贴译文」，一次四步、跨两个应用。对每天要写几十次外文的人，这是明显的效率断点。

瞬译把它压缩为**一次快捷键**：在任意输入框打完中文，按 `Alt+J`，原文位置直接变成译文——不切窗口、不走剪贴板、不联网。

**适用**：即时通讯、邮件与文档、浏览器输入框、代码注释。
**不适用**：追求文学级翻译质量的场景（本项目用轻量模型换即时响应）。

## 功能

- **全局热键翻译** — `keyboard` 全局钩子；回调只入队，翻译在工作线程跑，界面不卡
- **原地回写** — `paste`（写剪贴板 → Ctrl+V → 还原原内容）或 `type`（SendInput Unicode 直打），日文自动选后者
- **模型管理** — 多线程分块下载、断点续传、镜像切换、校验、安装、清理，全程可取消
- **图形设置界面** — tkinter 自绘：模型卡片、快捷键录制、翻译档位、回写模式、内存优化
- **系统托盘** — 常驻右键菜单；单实例互斥，二次启动唤起已有窗口
- **内存友好** — 15 分钟空闲自动卸载模型，再启用仅 0.15 s 重载

## 独特优势

1. **真·原地翻译** — 同类工具多为「划词弹窗 + 手动回填」；本项目处理了剪贴板还原、焦点保持、输入法状态、Unicode 直打整套细节，译文直接落在原位置
2. **完全离线** — 模型本地推理，无 API Key、无字数限制、聊天内容不出本机
3. **34 MB 单文件** — 解释器与依赖全内嵌，目标机器无需装任何环境
4. **快** — 高速档 26 ms/句；常驻内存与按需加载不必二选一
5. **现代观感，只用 tkinter** — Pillow 超采样替代 ClearType（消除彩边），自绘圆角卡片/胶囊/开关，DPI 感知，防闪烁弹窗；相比纯 tkinter 仅增约 2.9 MB
6. **可验证性** — 100+ 测试与诊断脚本，覆盖纯逻辑、真实网络下载、像素级视觉（描边完整性、居中偏差 dx=dy=0）

## 架构

**一次翻译的数据流**

```
按 Alt+J → keyboard 钩子（仅入队）→ service.py 工作线程
    ├─ capture.py    取词（选区 / 自动模式）
    ├─ engine.py     翻译（models.py 保证模型就绪）
    └─ injector.py   原地回写（含剪贴板备份还原）
→ 原文位置出现译文
```

**分层原则**

- `service.py` 是**唯一中枢**：热键/引擎/回写互不直接引用，控制台版因此能复用同一链路而不带 GUI
- `ui_kit.py` 是**视觉唯一来源**：业务代码不出现颜色与圆角字面量
- `notify.py` / `dialogs.py` 各为**唯一入口**：禁止散落的 messagebox 与各自为政的通知判定
- `tools/` 可整体删除而不影响运行（但会失去回归能力，故随库保存）

## 快速开始

```bash
# 源码方式（需 Python 3.10+）
双击 0-准备环境.bat   # 建虚拟环境并装依赖
双击 2-托盘版.bat     # 启动，首次使用按提示下载模型

# 成品方式（无需 Python）
双击 瞬译.exe
```

任意应用中输入中文 → `Alt+J` → 原地变译文。

> ⚠️ 程序所在路径必须为**纯 ASCII**（sentencepiece 的 C++ 实现打不开含中文的路径）。
