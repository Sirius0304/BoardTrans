# 阶段二：托盘常驻完整版 · 保姆级运行指南

## 这个阶段新增了什么

| 新增能力 | 说明 |
|---|---|
| **托盘常驻** | 程序缩到右下角小图标，关掉命令行窗口也不退出 |
| **中→日** | 托盘菜单一键切换目标语言（首次切日文会自动下载 115 MB 模型） |
| **两档质量** | 托盘菜单切换"高速度 / 高质量" |
| **总开关** | 不想用的时候一键关掉，不用退出程序 |
| **状态记忆** | 语言、档位、开关全部落盘，**重启后自动恢复上次的选择** |
| **快捷入口** | 托盘菜单可直接打开配置文件、数据目录、日志 |

## 运行

**双击 `2-托盘版.bat`**（或命令行执行 `.venv\Scripts\python.exe run_stage2.py`）

预期输出：

```
键译 正在启动...
  数据目录: C:\Users\你的用户名\AppData\Local\BoardTrans
  [OK] 服务已启动，程序驻留在系统托盘（右下角小图标）
      右键托盘图标可切换语言/档位、开关翻译、退出
```

同时右下角通知区域会出现一个**蓝色圆形、中间写着"译"**的小图标。

> 如果已经有模型（阶段一跑过了），启动是秒开的；
> 如果还没装模型，会先在这个窗口里带进度条下载，进度看得见。

## 托盘菜单怎么用

**右键**（或左键）点击右下角那个蓝色"译"图标，会看到菜单：

```
当前：英文 · 高速度
快捷键：alt+j
────────────────
目标语言          ▶  英文 / 日文
翻译档位          ▶  高速度 / 高质量
启用翻译              ✔
────────────────
打开配置文件
打开数据目录
打开日志
使用说明
────────────────
退出
```

### 切换目标语言

右键托盘 → 点 `目标语言` → `日文`；也可以在**设置窗口 →「目标语言」区块**里切换（2026-09-29 起，
两边是同一项设置，任改一处另一处会自动同步）。

- 若之前没用过日文，程序会**在后台自动下载**英文→日文模型（115 MB），
  期间右下角会弹通知显示下载进度。**下载期间中→英翻译照常可用**，不用等。
- 下载完成后会弹 `模型下载完成` 通知，之后打中文按 `Alt+J` 就出日文了。

**实测样例**（中文 → 日文）：

| 原文 | 译文 |
|---|---|
| 你好，今天天气不错。 | こんにちは、それは素晴らしい一日です。 |
| 我们明天下午三点开个会，讨论一下项目进度。 | 明日3:00に会議をし、プロジェクトの進捗を議論します。 |
| 请把这份文件打印出来，放在我的桌子上。 | プリントアウトして、デスクに置いてください。 |

### 切换翻译档位

点 `翻译档位` → `高质量`（菜单里会打勾）。

| 档位 | 中→英 实测 | 中→日 实测 | 适合场景 |
|---|---|---|---|
| 高速度 | 平均 26 ms/句 | 平均 87 ms/句 | 日常聊天、快速随手翻 |
| 高质量 | 平均 54 ms/句 | 平均 109 ms/句 | 邮件、文档、正式内容 |

### 开关翻译

点 `启用翻译` 取消勾选即可临时关闭（图标会变成灰色）。
关掉后按快捷键会弹出提示"翻译已关闭"，不会误翻译。

## 验证"状态记忆"（需求硬指标）

1. 右键托盘 → 目标语言选 `日文`，档位选 `高质量`
2. 右键托盘 → `退出`
3. 重新双击 `2-托盘版.bat`
4. 右键托盘看菜单第一行，应该显示：**`当前：日文 · 高质量`**

也可以直接打开配置文件确认（托盘菜单 → `打开配置文件`）：

```json
{
  "hotkey": "alt+j",
  "target_lang": "ja",
  "quality": "quality",
  "enabled": true,
  ...
}
```

> 实现上，每次切换都会执行"写临时文件 → 强制刷盘 → 原子替换"三步，
> 所以**即使直接关机、强杀进程，配置也不会损坏、不会丢失**。

## 配置文件说明

位置：`C:\Users\你的用户名\AppData\Local\BoardTrans\config.json`
（也可从托盘菜单 → `打开配置文件` 直接打开）

| 字段 | 默认值 | 可选值 | 说明 |
|---|---|---|---|
| `hotkey` | `alt+j` | 任意组合键，如 `ctrl+alt+j`、`f9` | 触发翻译的快捷键 |
| `target_lang` | `en` | `en` / `ja` | 目标语言 |
| `quality` | `fast` | `fast` / `quality` | 翻译档位 |
| `enabled` | `true` | `true` / `false` | 总开关 |
| `inject_mode` | `paste` | `paste` / `type` | 回写方式。`type` 完全不碰剪贴板 |
| `restore_clipboard` | `true` | `true` / `false` | 粘贴回写后是否还原原剪贴板 |
| `capture_mode` | `auto` | `auto` / `selection` / `line` | 取词方式，见下 |
| `max_chars` | `20000` | 数字 | 单次取词上限，超过就不翻译（防止误选整篇文档）。2026-10-12 由 2000 提高——旧值会把一个普通长段落或一个 txt 文件直接拒掉 |

**关于 `capture_mode` 三个值的区别**：

| 值 | 行为 | 什么时候用 |
|---|---|---|
| `auto`（默认） | 先看你有没有选中文字，有就用选中的；没有就自动取**光标所在整段** | 绝大多数场景 |
| `selection` | 只翻译"你手动选中"的内容 | 想完全掌控翻译范围，或某些软件里自动取词不准 |
| `line` | 总是取光标到本行行首（只翻这一句） | 只想翻当前这一句时 |

**改完配置文件要重启程序**（托盘菜单 → 退出 → 重新打开）才会生效。

## 常见问题

| 现象 | 原因与解决办法 |
|---|---|
| 托盘图标找不到 | Windows 11 默认把新图标收进"隐藏的图标"里。点任务栏右下角的 `^` 箭头，把"译"图标拖到任务栏上常驻 |
| 切到日文后按快捷键没反应，提示"模型未就绪" | 日文模型（115 MB）还在后台下载。等通知提示下载完成即可；或看日志确认进度 |
| 托盘菜单里全是英文/乱码 | 这是系统字体问题，不影响功能；可忽略 |
| 弹窗通知看不到 | Windows 的"专注助手/勿扰模式"会屏蔽通知。所有事件在日志里都有记录（托盘菜单 → 打开日志） |
| 想让它开机自动启动 | 按 `Win+R` 输入 `shell:startup` 回车，把 `2-托盘版.bat` 的**快捷方式**拖进去即可（右键 → 新建快捷方式，目标填 `F:\shunyi\2-托盘版.bat`） |
