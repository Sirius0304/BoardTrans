# 设置界面 · 阶段一指南：窗口骨架 + 托盘入口 + 保存闭环

> 本阶段目标：托盘右键能看到「设置…」，点击后窗口打开；窗口里改的东西点「保存」后
> 立刻生效，关掉软件重开还是新值。

---

## 一、⚠️ 先做这一步：确认你的 Python 带 tkinter

设置界面用的是 Python 自带的 tkinter 图形库（为了不让 exe 体积膨胀，见 `设置界面-方案说明.md`）。
**Python 官网下载的安装包默认自带 tkinter，但精简版/绿色版可能没有。**

先检查一下，打开命令行（`Win + R` → 输入 `cmd` → 回车），执行：

```bat
cd /d F:\shunyi
.venv\Scripts\python.exe -c "import tkinter; print('tkinter 可用, Tk版本', tkinter.TkVersion)"
```

**预期看到**：

```
tkinter 可用, Tk版本 8.6
```

**如果报错** `ModuleNotFoundError: No module named 'tkinter'`，说明当前 Python 是精简版，
需要换成官网完整版重新搭环境（下面第二、三步）。

> 本机情况：原先项目用的 Python 是精简版（没有 tkinter），已经改用系统里的
> `C:\Users\yz050\AppData\Local\Programs\Python\Python313\python.exe`（Python 3.13.15）
> 重建了 `.venv`，**你现在直接跳到第四步验证即可**。
> 下面第二、三步是"换电脑 / 重装"时的完整流程，照着做就行。

## 二、重新搭建带 tkinter 的环境（换电脑或需重装时看这段）

### 1. 安装官方 Python（已装可跳过）

到 <https://www.python.org/downloads/windows/> 下载 **Windows installer (64-bit)**，
安装时**务必勾选 `Add python.exe to PATH`**，以及保持默认勾选的 `tcl/tk and IDLE`
（这一项就是 tkinter，**不要取消**）。

验证：

```bat
python --version
```

### 2. 用这个 Python 重建虚拟环境

```bat
cd /d F:\shunyi
```

把旧的 `.venv` 改名留个备份（改名比删除安全，也避免误删）：

```bat
ren .venv .venv_old
```

创建新环境：

```bat
python -m venv .venv
```

**预期结果**：没有任何输出（没有输出就是成功），目录下出现新的 `.venv` 文件夹。

### 3. 安装依赖

```bat
.venv\Scripts\python.exe -m pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/
```

**预期看到最后几行**：

```
Successfully installed ctranslate2-4.8.2 keyboard-0.13.5 Pillow-12.3.0
pyperclip-1.11.0 pystray-0.19.5 sentencepiece-0.2.2 pyinstaller-6.22.3 ...
```

> ⚠️ 一定要带 `-i https://mirrors.aliyun.com/pypi/simple/`。
> 实测清华镜像**缺少 ctranslate2**，不加会报
> `Could not find a version that satisfies the requirement ctranslate2`。

### 4. 确认 tkinter 与新环境都正常

```bat
.venv\Scripts\python.exe -c "import tkinter, ctranslate2, keyboard, pystray, pyperclip, PIL; print('全部就绪, Tk', tkinter.TkVersion)"
```

**预期看到**：`全部就绪, Tk 8.6`

## 四、验证：打开 → 保存 → 重启仍是新值

### 第 1 步：启动程序

双击 `2-托盘版.bat`（或命令行 `.venv\Scripts\python.exe run_stage2.py`）。

**预期看到控制台输出**：

```
瞬译 正在启动...
  数据目录: C:\Users\你的用户名\AppData\Local\ShunYi
  [OK] 服务已启动，程序驻留在系统托盘（右下角小图标）
      右键托盘图标 →「设置…」可管理模型、翻译档位和快捷键
```

右下角出现蓝色「译」图标（如果没看到，点任务栏右下角的 `^` 箭头找）。

### 第 2 步：从托盘打开设置

**右键**（或左键）点击托盘上的蓝色「译」图标 → 菜单里点 **「设置…」**。

**预期看到**：弹出标题为「瞬译 · 设置」的窗口，界面从上到下是：

```
┌ 瞬译 设置 ─────────────────────────────────────────┐

│                                                     │
│ ┌ 翻译模型 ──────────────────────────────────────┐ │
│ │ 提示：下载模型是本软件唯一需要联网的操作…        │ │
│ │  中译英  中文→英文  约 71 MB      [删除]        │ │
│ │  状态：已下载（占用 82 MB）                      │ │
│ │  中译日  中文→日文  约 115 MB     [删除]        │ │
│ │  状态：已下载（占用 128 MB）                     │ │
│ └────────────────────────────────────────────────┘ │
│ ┌ 翻译档位 ──────────────────────────────────────┐ │
│ │  (•) 高速度   响应快，适合日常聊天、随手翻译     │ │
│ │  ( ) 高质量   更准确，适合邮件、文档等正式内容   │ │
```

> 窗口可以最小化、可以拖拽、可以关闭。**关闭后软件继续在托盘里运行**。

### 第 3 步：改档位并保存

1. 在「翻译档位」里点 **「高质量」**
2. 窗口**底部（按钮行上方）**出现黄色提示条：`有未保存的修改。当前实际生效的是：快捷键 Alt+J、档位 高速度。点「保存」后生效。`
3. 点右下角 **「保存」**
4. 弹出提示：`设置已保存并立即生效，无需重启软件。`

### 第 4 步：确认立即生效

**不用重启**，随便打开记事本打一句中文，按 `Alt+J`，译文照样出来（现在走的是高质量档）。

也可以用托盘菜单确认：右键托盘图标，第一行应显示 `当前：英文 · 高质量`。

### 第 5 步：确认重启后仍是新值（关键验证）

1. 右键托盘图标 → **「退出」**
2. 重新双击 `2-托盘版.bat`
3. 右键托盘图标，第一行应显示 **`当前：英文 · 高质量`** ✅
4. 再打开「设置…」，「高质量」应该还是选中的

### 第 6 步：验证"取消"不生效

1. 打开「设置…」，把档位改成「高速度」（**先不要保存**）
2. 直接点窗口右上角 ✕
3. **预期**：弹出确认框 `有未保存的修改，关闭后会丢弃，确定吗？` → 点「确定」
4. 重新打开「设置…」，应该仍然是「高质量」（说明刚才的修改没生效）

## 六、常见报错与解决

| 报错 / 现象 | 原因 | 解决办法 |
|---|---|---|
| `ModuleNotFoundError: No module named 'tkinter'` | Python 是精简版，不带图形库 | 按本文第二节换官网完整版 Python 重建环境 |
| 点「设置…」弹出"设置界面需要用到 Python 自带的 tkinter 图形库…" | 同上（程序的兜底提示，翻译功能不受影响） | 同上；或暂时直接编辑 `config.json` |
| 点「设置…」没反应 | 窗口正在创建（首次约 1~2 秒） | 稍等；若一直没有，看日志 `...\ShunYi\logs\shunyi.log` |
| 窗口打开是空白/花的 | 高 DPI 缩放异常 | 关掉窗口重开一次；或把系统缩放临时设为 100% 验证 |
| 界面文字被截断 | 系统字体缺失（极罕见） | 界面统一用「微软雅黑」（ClearType 渲染最锐利）；缺雅黑时依次回退雅黑旧名/黑体/SimHei；如果还是异常，反馈日志 |
| `无法使用「XXX」` | 新快捷键被占用 | 换一个组合（例如 `ctrl+alt+j`），程序已自动保留原快捷键，不会失去响应能力 |
| 保存后按快捷键没反应 | 该组合被其他软件抢占了（用钩子实现的软件无法自动检测） | 换一个更复杂的组合，如 `ctrl+shift+alt+T` |
| 托盘找不到图标 | Windows 11 默认收纳新图标 | 点任务栏右下角 `^` 箭头，把「译」图标拖到任务栏上常驻 |
