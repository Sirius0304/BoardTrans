# 设置界面 · 阶段三指南：模型管理（下载 / 进度 / 取消 / 删除）

> 本阶段目标：在设置窗口里管好两个翻译模型——没装的能下载（带进度、能取消），
> 装好的能删除（有二次确认、告诉你释放多少空间），所有失败都有看得懂的原因。

---

## 三、下载模型

### 为什么要下载

翻译引擎本身不联网，但**模型文件**（相当于"翻译辞典"）需要先下载一次，之后永久离线可用。
这是**整个软件唯一需要联网的操作**，界面上已经用橙色字明确标出来了。

### 操作步骤

1. 点模型右边的 **「下载」**
2. 弹出确认框：

   ```
   ┌ 开始下载模型 ──────────────────────────────────────┐
   │ 即将下载：中译英（约 71 MB）。                       │
   │                                                     │
   │ 这是本软件唯一需要联网的操作，翻译过程本身完全离线。  │
   │ 下载可以随时点「取消」，已经下载的部分下次会接着下。  │
   │                                        [确定] [取消] │
   └─────────────────────────────────────────────────────┘
   ```
3. 点「确定」→ 状态变成 `正在下载 3%　（2.1 / 71.0 MB）`，下方出现进度条
4. 下载期间**设置窗口不会卡死**，你可以继续切档位、改快捷键，托盘和其他功能也都正常
5. 下载完成后弹窗：

   ```
   模型已下载并安装完成，现在可以正常翻译了。    [确定]
   ```
   卡片变成 `状态：已下载（占用 82 MB）`，按钮变成「删除」

> **中译日会自动带上基础模型**：如果中译英还没装，点中译日的下载会提示
> "注意：日文方向还需要「中译英」基础模型（约 71 MB），本次会一并下载。"

### 取消下载

下载中点 **「取消」**：

1. 状态变成 `正在取消…`
2. 一两秒内停下，弹窗提示 `下载已取消`
3. 已经下载的部分**保留在磁盘上**，下次再点「下载」会**从断点继续**，不会白下

### 下载失败

**你会看到**一个错误弹窗，里面是"人话版"的原因，例如：

| 实际情况 | 提示文字 |
|---|---|
| 网络超时 | `网络超时：连接下载服务器超时了。请检查网络后重试。` |
| 完全连不上 | `网络不通：无法连接到下载服务器。请检查网络或稍后重试。` |
| 磁盘满了 | `磁盘空间不足：请清理磁盘后重试。` |

弹窗末尾还会告诉你手工兜底的办法：

```
可以点击「下载」重试。
若反复失败，可手动下载模型包放到：
C:\Users\你的用户名\AppData\Local\ShunYi\packages_cache
```

**重试**：直接再点一次「下载」即可（会自动跳过多余的重复下载）。

**手工兜底的具体做法**（网络受限时最有效）：

1. 用浏览器（或手机热点）打开下面地址，把文件下下来：
   - `https://argos-net.com/v1/translate-zh_en-1_9.argosmodel`（71 MB，必需）
   - `https://argos-net.com/v1/translate-en_ja-1_1.argosmodel`（115 MB，只用日文才需要）
2. 放进 `C:\Users\你的用户名\AppData\Local\ShunYi\packages_cache\`
3. **重命名为** `zh_en.argosmodel` 和 `en_ja.argosmodel`（名字必须一样）
4. 回到设置窗口点「下载」——程序会发现本地已有完整包，直接解压安装，不再联网

## 四、删除模型

### 操作步骤

1. 点已安装模型右边的 **「删除」**
2. 弹出二次确认框（会明确告诉你影响）：

   ```
   ┌ 删除模型 ──────────────────────────────────────────┐
   │ 确定要删除「中译英」模型吗？                         │
   │                                                     │
   │ 将释放约 82 MB 磁盘空间。                            │
   │ 注意：中译英是基础模型，删除后中译英和中译日都无法翻译。│
   │ 当前目标语言正在使用它，删除后按快捷键会提示模型缺失。 │
   │                                                     │
   │ 删除后如果还需要，可以在这里重新下载。                │
   │                                        [确定] [取消] │
   └─────────────────────────────────────────────────────┘
   ```
3. 点「确定」→ 完成后：

   - 如果删除后当前目标语言**还缺模型**，会弹警告：
     `删除完成，释放了 82 MB。当前目标语言所需的「中译英」模型已缺失，现在按快捷键会提示模型未就绪，请重新下载后再使用。`
   - 如果不缺，弹 `删除完成，已删除，释放了 82 MB 磁盘空间。`

> **不会静默失效**：删完之后如果你按快捷键，托盘会弹「模型还没下载」并**自动打开设置窗口**，
> 引导你重新下载，而不是无声无息地什么都不做。

### 删除正在被占用的模型

程序在删除前会先让翻译引擎**卸载模型、释放文件句柄**，所以正常情况下能顺利删掉。

万一文件真的被其他程序占用（例如你手工开过模型目录里的文件），你会看到：

```
┌ 无法删除 ───────────────────────────────────────────┐
│ 模型文件正在被占用，删除没有执行。                    │
│                                                     │
│ 请先把目标语言切到另一个方向，或退出软件后手动删除该文件夹。│
│                                            [确定]    │
└────────────────────────────────────────────────────┘
```

**软件不会崩，也不会留下半删状态**。

## 五、首次运行、一个模型都没有时会发生什么

1. 双击 `2-托盘版.bat` 启动
2. 控制台会打印：
   ```
   检测到缺少翻译模型：中文 → 英文（基础模型）
   正在打开设置窗口，请在「翻译模型」区域点「下载」
   ```
3. **设置窗口自动弹出**（约 2 秒后），模型卡片显示 `状态：未下载`
4. 另一种情况：如果你直接按了快捷键想翻译，托盘会弹
   `模型还没下载：缺少…。已为你打开设置窗口，点「下载」即可。`，同样自动打开设置窗口

## 七、常见报错与解决

| 现象 | 原因 | 解决办法 |
|---|---|---|
| 进度长时间停在 0% | 正在建立连接（TLS 握手），或网络极慢 | 等 10~30 秒；若一直不动，点「取消」后重试 |
| 下载到 99% 失败 | 网络抖动 | 直接再点「下载」，会从断点续传，不用从头来 |
| 点「下载」没反应 | 上一次的下载线程还没结束 | 等几秒；或看日志确认状态 |
| 下载完但仍提示模型未就绪 | 文件解压不完整 | 点「删除」后重新下载；或删掉 `...\ShunYi\packages\<key>` 再试 |
| 删不掉 | 文件被其他程序占用 | 按弹窗提示：切换目标语言或退出软件后重试 |
| 磁盘空间不够 | 模型解压后约 210 MB，加压缩包约 400 MB | 清理 C 盘空间 |
| 公司网络下不动 | 防火墙限制 | 按上面"手工兜底"用手机热点下载后放进 `packages_cache` |
