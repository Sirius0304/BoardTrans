# 瞬译 · 上下文摘要（交接/压缩版）

> 用途：把长会话压缩成可继续推进的最小上下文。更新于 **2026-10-03 21:10**。
> 过程细节见 `.workbuddy/memory/2026-10-01.md` 与 `2026-10-03.md`（当天逐条记录）；

## 1. 项目目标（一句话）

Windows 桌面工具「瞬译」：任意应用里打完中文 → 按 `Alt+J` → 原文**原地变成**英文/日文。
完全离线（本地 CTranslate2 + OPUS-MT），托盘常驻，可打包成单文件 exe。

### 4.3 弹窗防闪烁：核心结论（务必先读）

**alpha 方案是错的。** 窗口合成由 **dwm.exe（独立进程）**完成，窗口一被映射就可能已
出帧，Python 层事后设 `attributes("-alpha", 0)` **来不及**（第一版实测照样闪）。

**定案时序**：`创建即 withdraw()` → 撤隐期用 `RoundedCard.fit_now()` 量准尺寸 →
`geometry("WxH+X+Y")` 一次写对 → 再 `deiconify()`。只有"从未被映射"才真正不被画出来。

连带修掉的坑：frameless 弹窗不扣边框偏移（扣了反偏 8/31px）；`_hide_close_button`
须在映射后调用；顺序须先露面再 `grab_set`；撤隐期不能问外层 Frame 要 req（恒 1×1）。

**方法论教训**：视觉时序类报障，帧级/像素级取证是唯一可靠手段；"进程内属性"挡不住
"进程外合成器"——跨进程时序问题要在"让对象压根不出现"这一层解决。

## 5. 设置窗口的既定设计约定（后续改动必须遵守）

- 布局顺序：标题 → 可滚动内容区（翻译模型 / 目标语言 / 翻译档位 / 内存优化 / 快捷键）→ 底部固定区
- 提示分两种，别混：**底部常驻黄条**（有未保存改动，pack 占位）/ **底部浮动小框**（保存结果，place 浮层，
  折行宽度按窗口宽度动态算、`3~7 秒`自愈）
- 保存结果三态：成功=绿 / 无需保存=蓝 / 快捷键冲突失败=红；**不弹 messagebox**
- **弹窗只用在"有破坏性 / 需要用户决策"的地方，不用在"汇报结果"上**（2026-10-03 确立）：
  现在**只有删除模型前的确认框**、点「取消」放弃修改这两处还会弹模态框。
  下载不弹框、删除完成后不弹框、「恢复默认设置」不弹、点 × 关窗不弹
- 视觉令牌全在 `app/ui_kit.py`（页底 `#F7F8FA`、卡片白、描边 `#D9DEE5`、主色 `#3B82F6`、TONES 语义色）
- 界面文字一律用 `ui.TextLabel`（接口与 `tk.Label` 兼容，`cget` 也返回原名）
