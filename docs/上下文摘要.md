# 瞬译 · 上下文摘要（交接/压缩版）

> 用途：把长会话压缩成可继续推进的最小上下文。更新于 2026-10-01。
> 更细的过程记录见 `.workbuddy/memory/2026-09-2*.md`、`2026-09-30.md`、`2026-10-01.md`；
> 长期约定见 `.workbuddy/memory/MEMORY.md`。

## 1. 项目目标（一句话）

Windows 桌面工具「瞬译」：任意应用里打完中文 → 按 `Alt+J` → 原文**原地变成**英文/日文。
完全离线（本地 CTranslate2 + OPUS-MT），托盘常驻，可打包成单文件 exe。

## 2. 硬约束（不可动摇，改前先读 MEMORY.md 对应条目）

| # | 约束 |
|---|---|
| 1 | 用 `ctranslate2.Translator` + `sentencepiece` 直接加载解压后的模型，**不引入 argostranslate**（会拖进 PyTorch/stanza） |
| 2 | 数据目录必须**纯 ASCII**：`%LOCALAPPDATA%\ShunYi`（sentencepiece 读不了中文路径）；路径统一走 `app/paths.py` 且**结果缓存**（写探针很慢）。`models_root()` 缓存与"来源值"绑定 → 配置热生效，无需重启 |
| 3 | 模型源：`zh_en` 71MB、`en_ja` 115MB（argos-net）；日文方向 `JA_MIN_BEAM = 3`（beam=1 严重错译） |
| 4 | 回写默认 `paste`（剪贴板+Ctrl+V+还原）；`type` 模式用 SendInput Unicode，`INPUT` 结构体 union 必须含 MOUSEINPUT（64 位 sizeof=40） |
| 5 | 配置落盘：临时文件 → `fsync` → `os.replace`（原子替换）；热键回调只入队，耗时工作在 `service.py` 工作线程 |
| 6 | 打包用项目根 `瞬译_精简.spec`（`collect_dynamic_libs` 只收原生库 + excludes numpy/converters/specs）→ 34 MB；**不要**退回 `--collect-all ctranslate2` |
| 7 | `.bat` 里只用半角标点、必须 CRLF（全角会让 cmd 报 `'34' is not recognized`） |
| 8 | 通知必须走唯一入口 `app/notify.py`（开关只在该入口判定一次 + 同事件 3 秒去重）；托盘只注入"怎么发" |
| 9 | 分块下载＝切片入队 + 线程动态领取（勿退回静态均分）；单片 `STALL_TIMEOUT=20`、失败重试 3 次 |
| 10 | 界面字体统一**微软雅黑**（族名候选：雅黑三个名字 → 黑体 → SimHei，回退写日志）；ttk 样式 font 只能写**命名字体名**（元组会被当字体描述 → 静默回退宋体）；ttk 主题必须 clam（vista 忽略字体） |
| 11 | **冻结环境可靠性**：Pillow 是**可选增强**（组件与文字的清晰度靠它），缺失/字体文件找不到时自动退回 Tk 矢量绘制与原生文字渲染，功能不受影响；`tk.StringVar/BooleanVar` 必须带 `master=`；量文字宽度用控件自身 `font measure`（不要 `tkinter.font.Font()`） |
| 12 | **清晰度**：进程必须先 `ui_kit.enable_dpi_awareness()`（早于任何窗口）；字号用**整数像素**；像素型设计值过 `ui_kit.S()` 随 DPI 缩放 |
| 18 | **文字渲染**（2026-10-01）：界面文字不再交给 Tk 的 ClearType 亚像素绘制（16× 放大下笔画边缘是彩虹色、轮廓被次像素位置扭曲），改由 `ui_kit.TextLabel` 用 Pillow **灰度超采样**渲染成图（3× 绘制 + BOX 降采样）。**尺寸必须与原生 Label 逐像素一致**：宽度用 Tk `font measure`、高度用 Tk `linespace`，`padx/pady` 要画进图片（含图片的 Label 会忽略 pad）。多行（wraplength）由 Tk 先排出"几行 + 内容宽"，再让 `wrap_to_lines` 凑出同样的行数。命名字体的像素字号由建字方 `ui.register_font()` 登记（**不要**从 `font actual` 反推：它返回四舍五入后的磅值，非 100% DPI 下会差 1px）。回归：`tools/test_text_crisp.py`（26 项）+ 效果图 `tools/make_text_showcase.py` |
| 17 | **弹窗统一风格**：界面弹窗一律走 `app/dialogs.py`（`ask`/`tell`），**不再使用 `tkinter.messagebox`**；同一套令牌（页面底/白圆角卡片/微软雅黑/`TONES` 语义色/`RoundedButton`/`ui.S()` 间距），`Esc`=取消、`Enter`=确认。「恢复默认设置」只弹**一次**确认框（结果反馈交给底部「未保存」提示条）。回归：`tools/test_dialogs.py`（20 项）+ 效果图 `tools/make_dialog_showcase.py` |
| 16 | **单实例运行**：`app/single_instance.py`（命名互斥体 `Local\ShunYi.SingleInstance` + 命名事件 `.ShowSettings` + 等待线程）；判定必须在**创建托盘之前**（`run_stage2.main()` 开头）；第二实例只发信号、用 `os._exit(0)` + 显式 flush 退出（`sys.exit()` 在冻结环境会挂）。**不要在第二实例里结束引导父进程**：实测会让子进程自己也不再退出（更糟），已回退；onefile 引导父进程的滞留属已知残留（无托盘/无窗口），解包目录由下次启动清理（spec 的 `datas` 里放了 `app_icon.ico` 作为自有标记）。回归：`tools/test_single_instance.py`（12 项，`--exe` 走真实 exe） |
| 15 | **超采样渲染**：自绘组件用 Pillow 在 `SUPERSAMPLE=3` 倍分辨率绘制 → BOX 降采样 → PNG 字节 → `PhotoImage(master=控件)` 作画布背景；**不可缓存 PhotoImage**（绑定解释器，跨窗口复用会失效），只缓存 PNG 字节；Pillow 缺失时自动退回矢量硬边画法。回归：`test_ui_crisp.py` I 段 + `render_stats()` |
| 14 | **组件清晰度**：所有自绘坐标/半径取整（半像素会让 1px 线摊成两层灰）；描边 `#D9DEE5`（原 `#E5E7EB` 在白底上对比不足，看着发虚）、强描边 `#C9D0DA`；图标笔画 ≥2px；阴影只在下/右各露 1px（不要整圈偏移的灰底）。回归：`tools/test_ui_crisp.py` H 段 |
| 13 | **响应性**：心跳 `_pump` 间隔 50ms、每轮最多 `PUMP_BUDGET=20` 条指令（防排空卡死）、单轮 >120ms 写警告；自绘控件**只在尺寸/配色变化时重画**，自检 250ms→稳定后退避 1s；滚轮**逐控件绑定**（禁用 bind_all）；跨线程操作 Tk 一律走 `settings.run_in_ui()`（tkinter 非线程安全）；`TextLabel` 值没变就**不重渲染**（刷新路径会反复 configure 同一文案）。**设置窗口必须预热**（2026-10-01）：界面懒加载会让首次点「设置」现建整个界面（270~330ms → 预热后 55~65ms），`run_stage2.main()` 里 `settings.prewarm()` 在后台先建好（窗口隐藏）；Tk 根窗口创建后**立刻 withdraw**（默认可见，否则闪半成品）。回归 `tools/test_prewarm.py`（13 项） |

## 5. 设置窗口的既定设计约定（后续改动必须遵守）

- 布局顺序：标题 → 可滚动内容区（翻译模型 / 目标语言 / 翻译档位 / 内存优化 / 快捷键）→ 底部固定区
  （未保存提示条 + 保存结果小框 + 按钮行）
- 提示分两种，别混：**底部常驻黄条**（有未保存改动，pack 占位）/ **底部浮动小框**（保存结果，place 浮层，3~7 秒自愈）
- 保存结果三态：成功=绿 / 无需保存=蓝 / 快捷键冲突失败=红；**不要再弹 messagebox**
- 仍保留模态的只有"需要用户决策的确认框"：删除模型、放弃未保存修改、恢复默认设置
- 视觉令牌全部在 `app/ui_kit.py`（页底 `#F7F8FA`、卡片白、描边 `#D9DEE5`、主色 `#3B82F6`、TONES 语义色）；
  改样式只改这个文件
- 界面文字用 `ui.TextLabel`（而不是 `tk.Label`）：接口兼容（`text`/`font`/`fg`/`bg`/`anchor`/`justify`/
  `wraplength` 都能照旧用，`cget` 也返回原名），只是把字渲染成图片；新增文字控件时请沿用
