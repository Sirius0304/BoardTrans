# 瞬译 · 上下文摘要（交接/压缩版）

> 用途：把长会话压缩成可继续推进的最小上下文。更新于 **2026-10-01 22:20**。
> 过程细节见 `.workbuddy/memory/2026-10-01.md`（当天逐条记录）；
> 长期约定见 `.workbuddy/memory/MEMORY.md`。

## 1. 项目目标（一句话）

Windows 桌面工具「瞬译」：任意应用里打完中文 → 按 `Alt+J` → 原文**原地变成**英文/日文。
完全离线（本地 CTranslate2 + OPUS-MT），托盘常驻，可打包成单文件 exe。

## 2. 硬约束（不可动摇，改前先读 MEMORY.md 对应条目）

| # | 约束 |
|---|---|
| 1 | 用 `ctranslate2.Translator` + `sentencepiece` 直接加载解压后的模型，**不引入 argostranslate**（会拖进 PyTorch/stanza） |
| 2 | 数据目录必须**纯 ASCII**：`%LOCALAPPDATA%\ShunYi`；路径统一走 `app/paths.py` 且**结果缓存**（写探针很慢）。`models_root()` 缓存与"来源值"绑定 → 配置热生效 |
| 3 | 模型源：`zh_en` 71MB、`en_ja` 115MB（argos-net）；日文方向 `JA_MIN_BEAM = 3`（beam=1 严重错译） |
| 4 | 回写默认 `paste`；`type` 模式用 SendInput Unicode，`INPUT` 的 union 必须含 MOUSEINPUT（64 位 sizeof=40） |
| 5 | 配置落盘：临时文件 → `fsync` → `os.replace`；热键回调只入队，耗时工作在 `service.py` 工作线程 |
| 6 | 打包用 `瞬译_精简.spec`（`collect_dynamic_libs('ctranslate2')` + excludes）→ **35.9 MB**；**不要**退回 `--collect-all` |
| 7 | `.bat` 只用半角标点、必须 CRLF |
| 8 | 通知唯一入口 `app/notify.py`（开关只在该入口判定一次 + 3 秒去重）；托盘只注入"怎么发" |
| 9 | 分块下载＝切片入队 + 线程动态领取；`STALL_TIMEOUT=20`、失败重试 3 次 |
| 10 | 界面字体统一**微软雅黑**；ttk 样式 font 只能写**命名字体名**（元组会被当字体描述→静默回退宋体）；ttk 主题必须 clam |
| 11 | **冻结环境可靠性**：Pillow 是**可选增强**，缺失/字体文件找不到时自动退回矢量绘制与原生文字渲染；`tk.StringVar/BooleanVar` 必须带 `master=`；量文字宽度用控件自身 `font measure` |
| 12 | **清晰度**：必须先 `ui_kit.enable_dpi_awareness()`（早于任何窗口）；字号用**整数像素**；像素型设计值过 `ui_kit.S()` |
| 13 | **响应性**：心跳 50ms/轮、每轮 ≤20 条、单轮 >120ms 写警告；自绘控件只在尺寸/配色变化时重画；滚轮逐控件绑定；跨线程一律走 `settings.run_in_ui()`；`TextLabel` 值没变就不重渲染。**设置窗口必须预热**：`run_stage2.main()` 里 `settings.prewarm()` 后台先建好（窗口隐藏）——懒加载会让首次点「设置」现建整个界面（270→60ms）；Tk 根窗口创建后**立刻 `withdraw()`**。回归 `tools/test_prewarm.py`(13) |
| 14 | **组件清晰度**：自绘坐标/半径取整；描边 `#D9DEE5`、强描边 `#C9D0DA`；图标笔画 ≥2px；阴影只在下/右露 1px |
| 15 | **超采样渲染**：自绘组件用 Pillow 3× 绘制 → BOX 降采样 → PNG 字节 → `PhotoImage(master=控件)`；**只缓存 PNG 字节**（PhotoImage 绑解释器，跨窗口失效）；Pillow 缺失退回矢量硬边 |
| 16 | **单实例**：`app/single_instance.py`（互斥体 + 命名事件 + 等待线程）；判定**必须在建托盘之前**；第二实例 `os._exit(0)`。**不要结束引导父进程**（实测更糟，已回退） |
| 17 | **弹窗统一风格**：一律走 `app/dialogs.py`（`ask`/`tell`），**禁止 `tkinter.messagebox`**。**位置**：`_center_on_parent` 让**客户区中心对齐父窗口中心** —— ①卡片靠 `<Configure>` 自适应，尺寸收敛前（实测中间值 26×56）不能算位置；②`wm geometry` 用**窗口框架**坐标、`winfo_rootx` 是**客户区**，差一个边框（实测 8/31px），按 `winfo_rootx − winfo_x` **一次性**补偿（**反复迭代会发散**）。`message=""` 不渲染说明文字。回归 `tools/test_dialogs.py`(30) |
| 18 | **文字渲染**：界面文字用 `ui.TextLabel`（Pillow 灰度超采样成图），**不要再用 `tk.Label` 显示文字**（Tk 走 GDI ClearType，16× 下笔画是彩虹色；彩边 14.8% → 0%）。尺寸与原生对齐：宽用 Tk `font measure`、高用 `linespace`、**`padx/pady` 画进图片**（含图片的 Label 会忽略 pad）。**多行按控件实际可用宽度断行**（`<Configure>` 重排，宽度变化 ≥4px 才动；`wraplength` 只当未布局时的初值）——**勿回退成"跟随 Tk 行数"**，那会让每行只填 3/5、右侧留白。断行要做**中文避头点**（`_NO_LINE_START` + `_punct_slack`，上限 16px）。字号由 `ui.register_font()` 登记。回归 `tools/test_text_crisp.py`(34) |

## 5. 设置窗口的既定设计约定（后续改动必须遵守）

- 布局顺序：标题 → 可滚动内容区（翻译模型 / 目标语言 / 翻译档位 / 内存优化 / 快捷键）→ 底部固定区
- 提示分两种，别混：**底部常驻黄条**（有未保存改动，pack 占位）/ **底部浮动小框**（保存结果，place 浮层，
  折行宽度按窗口宽度动态算、`3~7 秒`自愈）
- 保存结果三态：成功=绿 / 无需保存=蓝 / 快捷键冲突失败=红；**不弹 messagebox**
- **现在只有这些操作还会弹模态确认框**：删除模型、点「取消」按钮放弃修改、开始下载模型。
  「恢复默认设置」**不弹**（点了直接生效）、点右上角 **× 关窗也不弹**（直接回滚并隐藏）
- 视觉令牌全在 `app/ui_kit.py`（页底 `#F7F8FA`、卡片白、描边 `#D9DEE5`、主色 `#3B82F6`、TONES 语义色）
- 界面文字一律用 `ui.TextLabel`（接口与 `tk.Label` 兼容，`cget` 也返回原名）
