# 阶段一：控制台版 · 保姆级运行指南

## 这个阶段能做什么

得到**最小可用版本**：在任意软件里用中文打字 → 按 `Alt + J` → 原文原地变成英文。
界面是一个黑底白字的控制台窗口，功能只有"中→英、高速度档"这两项固定设置。

> 为什么先做控制台版？因为它把最容易出问题的环节（取词、翻译、回写）单独暴露出来，
> 出问题时控制台里会直接打印原因，比托盘版好排查得多。跑通之后再上阶段二。

---

## ⚡ 快速通道（本机环境已经准备好了）

如果你用的就是 `F:\瞬译` 这台电脑（Python 环境、依赖库、翻译模型都已经装好），
**直接双击 `1-控制台版.bat` 就行**，然后跳到本文最后的「第 7 步：试试效果」。

下面第 1～6 步是"从零开始"的完整流程，换一台新电脑时照着做即可。

---

## 从零开始

### 第 1 步：安装 Python

1. 打开 <https://www.python.org/downloads/windows/>
2. 下载 **Windows installer (64-bit)**，版本 3.10 以上都行（推荐 3.12 或 3.13）
3. 双击安装包，**务必勾选底部的 `Add python.exe to PATH`**，然后点 `Install Now`

**验证**：按 `Win + R`，输入 `cmd` 回车，在黑窗口里执行：

```bat
python --version
```

预期看到类似 `Python 3.13.12`（只要不是报错就行）。

> 如果提示 `'python' 不是内部或外部命令`，说明第 3 步没勾选 PATH。
> 重新运行安装包 → 选 `Modify` → 勾上 `Add Python to environment variables` → 再试一次。

---

### 第 2 步：把项目文件夹放到电脑上

把整个 `瞬译` 文件夹放到一个**路径简单、不要有空格**的位置，推荐：

```
F:\瞬译
```

> 项目文件夹本身可以用中文名，但**不要放在深层嵌套的目录**里，
> 也不要放桌面（桌面路径经常含中文用户名，个别工具会有兼容问题）。

---

### 第 3 步：打开命令行并进入项目目录

按 `Win + R`，输入 `cmd` 回车。然后依次执行（**逐行复制粘贴，每行按回车**）：

```bat
F:
```

```bat
cd \瞬译
```

> 如果项目放在别的盘，比如 D 盘 `D:\app\瞬译`，那就先 `D:` 再 `cd \app\瞬译`。
> 更省事的办法：在文件资源管理器里打开 `瞬译` 文件夹，点一下地址栏，
> 把里面的路径改成 `cmd` 再回车，命令行会直接开在这个目录。

**验证**：执行下面这行，应该能列出项目文件：

```bat
dir
```

预期看到 `run_stage1.py`、`app`、`requirements.txt`、`1-控制台版.bat` 等。

---

### 第 4 步：创建独立的 Python 环境（虚拟环境）

```bat
python -m venv .venv
```

这一步会创建一个叫 `.venv` 的文件夹（约 20 MB），需要几秒到几十秒，**没有输出就是成功**。

> 为什么要这一步？把项目需要的库装在独立环境里，不污染你系统里的 Python，
> 以后想彻底卸载，直接删掉 `.venv` 文件夹即可。

---

### 第 5 步：安装依赖库

```bat
.venv\Scripts\python.exe -m pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/
```

预期输出（最后几行）：

```
Successfully installed ctranslate2-4.8.2 keyboard-0.13.5 Pillow-12.3.0
pyperclip-1.11.0 pystray-0.19.5 sentencepiece-0.2.2 pyinstaller-6.22.3 ...
```

> ⚠️ **必须带 `-i https://mirrors.aliyun.com/pypi/simple/`**。
> 实测清华镜像**缺少 ctranslate2 这个包**，如果你电脑上默认配了清华源又不加 `-i`，
> 会报 `Could not find a version that satisfies the requirement ctranslate2 (from versions: none)`。

---

### 第 6 步：启动程序

**方式 A（推荐，小白友好）**：直接双击项目里的 `1-控制台版.bat`

**方式 B（命令行）**：

```bat
.venv\Scripts\python.exe run_stage1.py
```

**首次运行会自动下载翻译模型**（71 MB），你会看到这样的进度条：

```
  首次运行需要下载翻译模型（约 71 MB），请保持联网，下载完成后可永久离线使用。
  模型会保存到: C:\Users\你的用户名\AppData\Local\ShunYi\packages\zh_en

  中→英 基础模型 [##################----------]  66%  47.2/71.0 MB
```

下载完成后继续启动，最后看到：

```
  [OK] 模型下载并安装完成
  正在加载翻译引擎（首次约 2~5 秒）...
  [OK] 引擎就绪

--------------------------------------------------------------
  怎么用：
    1. 打开任意可输入文字的地方（记事本、微信、浏览器地址栏都行）
    2. 用中文打一句话，例如：今天天气不错
    3. 按快捷键  Alt + J
    4. 刚才那句话会原地变成英文译文
--------------------------------------------------------------
```

**看到这个界面就成功了**，保持这个黑窗口开着别关。

---

### 第 7 步：试试效果

1. 打开**记事本**（或微信、浏览器地址栏，任何能打字的地方）
2. 用中文输入：`今天天气不错` （**打完不要按回车，光标停在句末**）
3. 按快捷键 **`Alt + J`**
4. 屏幕上会弹出提示：`已翻译成英文（0.03s）`，同时输入框里的中文变成：

   ```
   Hello, it's a nice day.
   ```

**四个自测点**，建议都试一遍：

| 测试场景 | 操作 | 预期结果 |
|---|---|---|
| 记事本 | 打中文 → `Alt+J` | 原地变英文 |
| 微信/QQ 聊天框 | 打中文 → `Alt+J` | 原地变英文 |
| 浏览器地址栏 | 打中文 → `Alt+J` | 原地变英文（可能需要稍等 1 秒） |
| 断网测试 | 拔网线 → 打中文 → `Alt+J` | **依然正常翻译**（证明是纯离线） |

## 常见报错与解决

| 报错信息 | 原因 | 解决办法 |
|---|---|---|
| `'python' 不是内部或外部命令` | 安装 Python 时没勾选 PATH | 重新运行安装包 → Modify → 勾选 Add Python to environment variables |
| `Could not find a version that satisfies the requirement ctranslate2` | 用了不含该包的镜像源（清华源） | 命令末尾加上 `-i https://mirrors.aliyun.com/pypi/simple/` |
| `No module named 'app'` | 不在项目目录里执行 | 先 `cd` 到有 `run_stage1.py` 的那个目录再运行 |
| `[X] 模型下载失败` | 网络不通或被防火墙拦 | ① 浏览器打开 <https://argos-net.com> 测试能否访问；② 用浏览器手动下载 `translate-zh_en-1_9.argosmodel`，放进 `C:\Users\你的用户名\AppData\Local\ShunYi\packages_cache\` 后重新运行 |
| 按 `Alt+J` 没反应 | 快捷键被别的软件占用 | 打开 `C:\Users\你的用户名\AppData\Local\ShunYi\config.json`，把 `"hotkey": "alt+j"` 改成 `"hotkey": "ctrl+alt+j"`，重启程序 |
| 按 `Alt+J` 提示"没能取到文字" | ① 光标不在输入框里；② 目标窗口是管理员权限 ③ 安全软件拦截了模拟按键 | 先手动选中文字再按快捷键；或右键程序"以管理员身份运行"；或运行 `0-自检.bat` 看第 8 项结果 |
| 译文变成了英文但剪贴板内容被换了 | 程序已自动还原原剪贴板 | 若发现异常，把 `config.json` 里 `"inject_mode"` 改成 `"type"`（完全不用剪贴板） |
| 窗口一闪就没了 | 依赖没装全 | 在命令行里跑一次（方式 B），这样报错信息不会消失 |

## 运行自检工具

如果遇到任何问题，先运行一键自检：

**双击 `0-自检.bat`**

它会逐项检查并给出中文结论，其中包括最关键的一项：

```
[8/8] 键盘模拟能力（取词/回写的关键）
  [正常] 模拟键盘输入正常（取词与译文回写可用）
```

如果这一项显示 `[异常] 模拟键盘输入被系统拦截`，说明是**安全软件**在阻止本程序模拟按键
（常见于 360、火绒、企业管控软件）。解决办法：在该软件的"键盘防护/行为拦截"里放行本程序，
或把它加进白名单。
