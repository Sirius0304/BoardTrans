# 设置界面 · 阶段四指南：重新打包成 exe

> 本阶段目标：把带图形设置界面的版本，重新打包成**一个** exe，双击即用，不需要装 Python。

---

## 一、打包前必须确认的一件事

**打包用的 Python 必须自带 tkinter**，否则打出来的 exe 点「设置」会打不开窗口。

```bat
cd /d F:\shunyi
.venv\Scripts\python.exe -c "import tkinter; print('tkinter OK, Tk', tkinter.TkVersion)"
```

**预期**：`tkinter OK, Tk 8.6`

如果报 `No module named 'tkinter'`，先按 `docs/设置界面-阶段一指南.md` 第二节换官方完整版 Python 重建环境。

## 二、一键打包

**双击 `3-打包exe.bat`**，等 1~3 分钟。

如果不方便双击，也可以直接在命令行执行：

```bat
cd /d F:\shunyi
.venv\Scripts\pyinstaller.exe --noconfirm --clean --onefile --windowed ^
    --name "瞬译" ^
    --icon "app_icon.ico" ^
    --hidden-import pystray._win32 ^
    --collect-all ctranslate2 ^
    --collect-all sentencepiece ^
    --distpath "dist" ^
    --workpath "build" ^
    --specpath "build" ^
    run_stage2.py
```

## 三、打包参数为什么是这些（含本次的新变化）

| 参数 | 作用 | 本次是否有变化 |
|---|---|---|
| `--onefile` | 打成单个 exe | 不变 |
| `--windowed` | 不显示黑色控制台窗口 | 不变 |
| `--name "瞬译"` | exe 名字 | 不变 |
| `--icon "app_icon.ico"` | exe 图标 | 不变 |
| `--hidden-import pystray._win32` | 托盘后端，PyInstaller 有时分析不到 | 不变 |
| `--collect-all ctranslate2` | **必须**，否则 56.5 MB 的 `ctranslate2.dll` 不入包，exe 一跑就崩 | 不变 |
| `--collect-all sentencepiece` | 收集分词器原生模块 | 不变 |
| **tkinter / tcl-tk** | 设置界面的图形库 | **新增，但不需要额外参数** |

**关于 tkinter 不需要额外参数**：PyInstaller 内置了 `hook-tkinter.py`，
会自动把 `_tkinter.pyd`、`tcl86t.dll`、`tk86t.dll` 以及 tcl/tk 的脚本库（`tcl/` 目录）
一起收进 exe。所以只要**打包用的 Python 本身有 tkinter**，打出来的 exe 就能用。

**实测体积变化**：

| 版本 | exe 体积 |
|---|---|
| 设置界面之前 | 47.4 MB |
| 加了设置界面之后 | **50.1 MB**（+2.8 MB，就是 tcl/tk 运行时的体积）|
| **后续瘦身后** | **34.1 MB**（排除 numpy 与无用图片解码器，见 `docs/瘦身扫描报告.md`） |

> 这就是选 tkinter 而不是 PyQt 的原因：PyQt 会让 exe 直接涨到 120~180 MB。

## 四、验证打包后的 exe（重要）

### 方法 A：直接双击试（最直观）

1. 打开 `F:\shunyi\dist` 文件夹，**双击 `瞬译.exe`**
2. 首次启动要 5~10 秒（要解压约 52 MB 内容到临时目录），之后右下角出现蓝色「译」图标
3. **右键托盘图标 →「设置…」**
4. **预期**：设置窗口正常弹出，能看到两个模型卡片、档位单选、快捷键框

## 五、打包后的回归检查清单

打完包后，建议按这个清单过一遍（都是原有功能，确认没被新界面影响）：

| # | 检查项 | 怎么验 | 预期 |
|---|---|---|---|
| 1 | 托盘图标出现 | 看右下角（或 `^` 里） | 蓝色「译」图标 |
| 2 | 设置窗口能开 | 右键托盘 →「设置…」 | 窗口弹出 |
| 3 | 快捷键取词翻译 | 记事本打中文 → `Alt+J` | 原地变英文 |
| 4 | 托盘切档位 | 右键托盘 →「翻译档位」→ 高质量 | 设置窗口（若开着）跟着变 |
| 5 | 托盘切语言 | 右键托盘 →「目标语言」→ 日文 | 打中文按快捷键出日文 |
| 6 | 快捷键开关 | 右键托盘 →「启用翻译」取消勾选 | 按 `Alt+J` 提示"翻译已关闭"，图标变灰 |
| 7 | 设置持久化 | 改档位 → 退出 → 重启 exe | 托菜单第一行显示 `当前：… · 高质量` |
| 8 | 断网可用 | 断网后按快捷键 | 翻译照常（模型是离线的） |

## 六、常见报错与解决

| 报错 / 现象 | 原因 | 解决办法 |
|---|---|---|
| exe 双击后托盘没图标 | 首次启动要解压，需要 5~10 秒 | 稍等；仍没有就看日志 `...\ShunYi\logs\shunyi.log` |
| 点「设置…」弹"需要 tkinter 图形库" | 打包用的 Python 没有 tkinter | 换官方完整版 Python 重建 `.venv` 后重新打包 |
| 打包成功但 exe 一运行就报 DLL 错误 | 少了 `--collect-all ctranslate2` | 加上这个参数重新打包 |
| 打包报 `ModuleNotFoundError` | 某模块没被分析到 | 加 `--hidden-import 模块名` |
| exe 体积超过 100 MB | 误把大库也 `--collect-all` 了，或没加 `--clean` | 检查参数；加 `--clean` 重新打包 |
| 杀毒软件报毒 / 直接删掉 exe | PyInstaller 程序的常见误报（它会"模拟键盘输入"，行为特征敏感） | 把 `dist` 文件夹加白名单；或提交误报申诉 |
| 打包很慢（超过 5 分钟） | 首次打包或杀软实时扫描 | 正常，耐心等；把项目目录加进杀软排除项会快很多 |

## 七、交给别人用的时候

| 情况 | 说明 |
|---|---|
| 对方电脑上从没跑过本软件 | 把 `dist\瞬译.exe` 拷过去即可，双击运行。首次启动会自动提示下载模型（71 MB，切日文再补 115 MB），**只需联网一次**，之后永久离线 |
| 想连模型一起离线交付 | 把 `C:\Users\你的用户名\AppData\Local\ShunYi\packages\` 整个文件夹一起拷到对方机器的同样位置（约 210 MB），对方就完全不用联网了 |
| 想连配置一起给 | 再拷 `...\ShunYi\config.json`（可选） |
