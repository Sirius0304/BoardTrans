### 可删的两个大块，为什么能删

**① numpy（26.4 MB 未压缩）—— 推理根本用不到它**

- ctranslate2 的 `__init__.py` 里的原文注释写着：
  > converters and specs import torch (and, for converters, transformers) at module level.
  > Those dependencies are only needed to **convert models, not to run inference**,
  > so import these submodules on first use.
- 即：**只有"转换模型"才需要 numpy**，官方特意做成了延迟导入。
- 我实测过：把 numpy 彻底屏蔽后 `import ctranslate2` 成功、模型加载 581 ms、**翻译 20 ms 完全正常**。
- 之所以进了 exe，是因为我打包时用了 `--collect-all ctranslate2`，把 `converters/` 一起收进去了。

**② `PIL\_avif.pyd`（7.5 MB）—— 我们只用 Pillow 画个图标**

- 这个文件是 **AVIF 图片格式的解码器**，我们从头到尾只用 `Image.new` / `ImageDraw` / `ImageFont` 画那个 64×64 的圆形"译"字图标，不打开任何图片。
- 当然，Pillow 本体必须留（pystray 依赖它），只删这一个用不到的解码插件。

### `--onefile` vs `--onedir`

| | onefile（当前） | onedir |
|---|---|---|
| 分发形态 | 单个 exe ✅ | 一个文件夹（几十个文件） |
| 启动速度 | 慢（每次要把内容解压到临时目录，5~10 秒） | 快（约 1 秒） |
| 体积 | 略小（有压缩） | 略大（不压缩，约 90~100 MB） |
| 适合谁 | **你这个场景**（零基础用户、双击即用、方便拷贝） | 自己用、频繁启动 |

**结论：继续用 `--onefile`** —— 你的用户是完全不懂技术的人，单个文件双击即用的价值远大于启动快几秒。

### 是否启用 UPX 压缩

UPX 能再压 20~30%（exe 可能降到 28~30 MB），但代价是：
- **杀毒软件误报明显增加**（UPX 是很多恶意软件的常见特征）
- 启动时多一层解压开销

本软件因为要"模拟键盘输入"，本来就容易被杀软盯上。**不建议启用 UPX** —— 宁可多 10 MB，也不要让用户遇到"下载后被杀软删掉"。

### 模型是否被打包进 exe

**没有** ✅ 现状已经是最优设计：
- exe 里只有引擎代码（50 MB）
- 模型放在 `%LOCALAPPDATA%\ShunYi\packages\`（210 MB），首次运行时下载一次，之后永久离线
- **不存在"包内一份、目录里又一份"的重复**

## 八、exe 体积优化（优化前 / 优化后）

### 具体数字

| | 优化前 | 优化后 | 变化 |
|---|---|---|---|
| **exe 体积** | **50.1 MB** | **34.1 MB** | **−16.0 MB（−32%）** |
| 内部未压缩内容 | 132.4 MB | 约 98 MB | −34 MB |
| 平均启动耗时（双击→托盘就绪，3 次平均） | 1.95 s | **1.69 s** | **−0.26 s** |

### 改了什么

1. **不再用 `--collect-all ctranslate2`**，改用 `collect_dynamic_libs('ctranslate2')` 只收原生库。
   原来那句会把 `ctranslate2/converters`（模型转换工具）一起收进来，而它模块级 `import numpy`
   —— numpy 及其 OpenBLAS 就占了 26.4 MB。
2. **排除 numpy**：ctranslate2 官方注释明确写了这些依赖"只有转换模型才需要，推理不需要"。
   实测（把 numpy 彻底屏蔽后）：`import ctranslate2` 成功、模型加载 581 ms、翻译 20 ms 正常。
3. **过滤 Pillow 用不到的图片解码器**（`_avif.pyd` 单个 7.5 MB 等 5 个文件）：
   本程序只用 Pillow 画那个 64×64 的图标，从不打开图片文件。
4. 顺带排除打包工具自身与测试框架（PyInstaller / setuptools / pip / unittest / pytest …）。

优化后的打包参数写在 **`瞬译_精简.spec`**（项目根目录，已纳入版本管理），
双击 `3-打包exe.bat` 即可复现。

### 2. 想回退到精简前

```
把 F:\瞬译_备份_20260927\ 里的内容移回原位
```

- 模型缓存：`packages_cache\` → `C:\Users\你的用户名\AppData\Local\ShunYi\packages_cache\`
- 旧虚拟环境：`.venv_old_nogui\` → 移回项目根目录
