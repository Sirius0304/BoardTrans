# 运行方式：到底需不需要 Python？

一句话结论：**给主人日常使用不需要；只有开发和改代码才需要。**

## 一、两种运行方式

| 方式 | 主人双击什么 | 需要 Python 吗 | 适合谁 |
|---|---|---|---|
| **成品版** | `瞬译.exe` | **不需要** | 日常使用、给朋友用 |
| 开发版 | `1-控制台版.bat` / `2-托盘版.bat` | 需要 | 改代码、调功能的人 |

`瞬译.exe` 是用 PyInstaller 打包的**单文件程序**，Python 解释器和全部依赖
都已经压进这一个 34 MB 的文件里了。实测它的内部结构：

- `python313.dll` —— Python 解释器本体
- `base_library.zip` —— 标准库
- 22 个 `.pyd` + 53 个 `.dll` —— ctranslate2、sentencepiece、Pillow 等
  带原生代码的依赖
- 355 个纯 Python 模块（PYZ 压缩包内）—— pystray、keyboard、pyperclip 等

所以 exe 运行时**根本不去找系统 Python**，把它单独拷到任何一台
Windows 电脑上双击就能用（目标机器需要 Windows 10/11 64 位）。

## 二、主人日常怎么用

1. 拿到 `瞬译.exe`，放在一个**路径不含中文**的目录里
   （比如 `D:\瞬译\`或 `C:\ShunYi\`）
2. 双击 → 托盘出现图标
3. 第一次用会提示下载翻译模型（约 71 MB + 115 MB），下完就永久离线
4. 之后在任意软件里打中文，按 `Alt+J` 就变英文

> 为什么强调"路径不含中文"：sentencepiece 是 C++ 实现，
> 打不开含中文的路径（实测放在 `F:\瞬译\` 会报
> `NOT_FOUND: sentencepiece.model`）。这是唯一需要注意的地方。

## 三、什么时候才需要 Python

以下场景才需要装 Python：

- 想改代码 / 加功能
- 想跑回归测试（`tools/` 下那一百多个自测脚本）
- 想重新打包 exe（`3-打包exe.bat`）
- 想用源码方式调试

这时才需要跑一次 `0-准备环境.bat`（联网装依赖，约 1~3 分钟），
它会在项目里建一个独立的 `.venv` 环境，和系统其他 Python 互不干扰。

## 四、如果要发给朋友

只需要给两样东西：

- `瞬译.exe`
- 模型的**已解压目录** `models/packages/zh_en`（约 83 MB）

或者干脆让对方第一次运行时自己下载（71 MB，中文→英文；
如果要中日对照还需 115 MB 的英文→日文模型）。

想省事就把整个 `models/` 目录一起拷过去，对方打开就能直接用。

## 五、常见疑问

**Q：删掉 `.venv` 会影响 exe 运行吗？**
不会。exe 自带解释器，`.venv` 只是给开发用的。

**Q：exe 和 .bat 有什么区别？**
`.bat` 是源码入口（会弹黑色控制台窗口），exe 是打包好的成品（静默跑，
系统托盘常驻）。日常用 exe。

**Q：exe 会不会偷偷联网？**
翻译全程离线。只有第一次下载模型、以及检查更新（如果有）时联网。

**Q：一定要用管理员权限吗？**
不用。普通双击即可，不写注册表、不装服务。
