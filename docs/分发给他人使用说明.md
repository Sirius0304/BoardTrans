# 瞬译 · 分发给他人使用说明

> 结论先行：**可以直接发，对方双击即可用**，但有三件事必须一起给或提前告知。

---

## 一、对方需要的环境

| 项目 | 要求 | 说明 |
|---|---|---|
| 操作系统 | Windows 10 / 11 **64 位** | 32 位系统无法运行（打包目标是 64 位） |
| Python | **不需要** | exe 内嵌解释器与全部依赖 |
| 管理员权限 | **不需要** | 不写注册表、不装服务、不改系统设置 |
| 联网 | **首次需要** | 仅用于下载翻译模型；模型到位后完全离线 |
| 磁盘空间 | 约 250 MB | exe 34 MB + 模型 186 MB + 余量 |

**唯一硬性约束：解压后的路径必须是纯英文**（不能含中文、下划线以外的特殊字符）。
原因：翻译引擎的分词器（sentencepiece）是 C++ 实现，无法打开含中文的路径——
放在 `D:\桌面\瞬译\` 这类目录下会直接报 `NOT_FOUND`。

✅ 正确示例：`D:\ShunYi\`、`C:\Tools\Translate\`、`E:\瞬译\`
❌ 错误示例：`D:\桌面\瞬译\`、`C:\程序\翻译\`

> 若对方坚持用中文路径，程序会把模型自动改放到 `%LOCALAPPDATA%\ShunYi`（纯英文），
> 翻译本身仍可用，只是模型不再跟着软件目录走。程序不会因此报错。

## 二、必须一并提供的内容

### 方式 A：只发 exe（最简单，对方需自行下载模型）

```
瞬译.exe
```

对方首次启动会提示下载模型：中文→英文约 71 MB，中文→日文再约 115 MB。
**需要对方能联网**，且下载期间不能中断。

### 方式 B：连模型一起发（离线可用，推荐给不熟悉软件的人）

```
瞬译.exe
models\
├── cache\zh_en.argosmodel        （71 MB，可选，删了不影响运行）
└── packages\zh_en\               （83 MB，**必须**）
```

把整个 `models\packages\zh_en` 目录放在 exe 旁边即可离线使用。
若还需要中日对照，再带上 `models\packages\en_ja\`（129 MB）。

> `models\cache\` 里的 `.argosmodel` 原始包可以不带——它是下载缓存，
> 留着的好处是以后重装模型时不用重新下载。

## 三、可能被忽略的三个坑

### 1. Windows  Defender 可能误报

PyInstaller 打包的单文件 exe 常被杀毒软件启发式拦截（"未知发布者"）。
**处理**：让对方在「Windows 安全中心 → 保护历史记录」里点"允许"，或添加排除项。
这是打包程序的通病，与文件本身无关。

### 2. 中文用户名的机器

若对方的 Windows 用户名是中文，`%LOCALAPPDATA%` 路径会含中文，
程序会自动降级到 `C:\ProgramData\ShunYi`（纯英文）——**能正常工作**，
但配置和日志不在常规位置。若对方要自定义，可用环境变量 `SHUNYI_DATA_DIR` 指定。

### 3. 目标语言决定模型需求

- 只要**中→英**：只需 `zh_en`（71 MB 下载 / 83 MB 解压后）
- 需要**中→日**：必须额外装 `en_ja`（115 MB 下载 / 129 MB 解压后），
  程序内部走「中文→英文→日文」双跳翻译

发之前建议先自己确认一遍对方需要哪几种。

## 五、对方的常见疑问

**Q：为什么双击没反应？**
A：先等几秒（首次启动要初始化）；仍无反应多半被杀毒软件拦截，
看「Windows 安全中心 → 保护历史记录」里是否有拦截记录。

**Q：能放桌面吗？**
A：可以，但桌面路径若含中文（如 `C:\Users\张三\Desktop`），
模型会自动改放到 `%LOCALAPPDATA%\ShunYi`，功能不受影响。

**Q：会不会偷偷联网？**
A：翻译全程离线。只有首次下载模型时会联网；之后连检查更新都没有。

**Q：模型能删吗？**
A：`models\packages\zh_en` **不能删**，删了翻译会提示缺模型。
`models\cache` 里的下载包可以删。

**Q：换电脑怎么办？**
A：把 exe 和 models 目录一起拷过去即可，无需重新配置。
配置存在 `%LOCALAPPDATA%\ShunYi\config.json`（中文用户名机器则在
`C:\ProgramData\ShunYi\`）。

**Q：能多台电脑同时用吗？**
A：可以，互不影响。程序只在本登录会话内做单实例互斥（`Local\` 前缀），
不同用户、不同电脑各自独立。
