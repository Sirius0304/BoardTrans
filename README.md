# 键译（BoardTrans）· 打字即翻译

![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)
![Platform: Windows](https://img.shields.io/badge/Platform-Windows%2010%20%2F%2011-blue.svg)

> 在任意软件里用中文打字，按一下 `Alt + J`，刚才那句话**原地变成英文或日文**。
> 完全离线，不联网、不需要 API Key；托盘常驻，可打包成单个 exe。

| 项目 | 说明 |
|---|---|
| 平台 | Windows 10 / 11（64 位） |
| 翻译方向 | 中文 → 英文、中文 → 日文 |
| 引擎 | CTranslate2 + OPUS-MT 神经网络模型（本地推理） |
| 模型 | 186 MB（中→英 71 MB + 英→日 115 MB），只需下载一次 |
| 速度 | 中→英 26 ms/句（高速档）/ 54 ms（高质量档） |
| 体积 | 单文件 exe 约 34 MB，双击即用 |

## 快速开始

| 方式 | 做法 |
|---|---|
| **直接用（推荐）** | 双击 `键译.exe` |
| 源码运行 | `0-准备环境.bat` → `2-托盘版.bat` |
| 重新打包 | `3-打包exe.bat` → 项目根目录生成 `键译.exe` |
| 出问题 | 双击 `0-自检.bat`，逐项体检并给出修法 |

**用法**：在记事本 / 微信 / 浏览器地址栏里打中文 → 按 `Alt + J` → 原地变译文。
**设置**：右键托盘图标 →「设置…」→ 管理模型 / 切换档位 / 录制快捷键。

## 核心功能

- **原地替换** —— 译文直接落在原输入位置，不弹窗、不切窗口、不用复制粘贴
- **完全离线** —— 本地模型推理，无 API Key、无字数限制，输入内容不出本机
- **两档质量** —— 高速档贪心解码 26 ms / 高质量档束搜索 54 ms
- **两种回写** —— 剪贴板粘贴（粘贴后还原原剪贴板）/ Unicode 逐字输入，日文自动择路
- **中→日** —— 经英文中转，日文方向强制 `beam≥3`（实测 beam=1 会严重错译）
- **图形设置界面** —— tkinter 自绘，仅让 exe 增加约 2.9 MB
- **托盘常驻 + 单实例** —— 重复启动不产生第二个图标，而是唤起已有窗口
- **空闲省内存** —— 15 分钟未用自动卸载模型，再启用仅 0.15 s 重载

## ⚠️ 分发给他人时请一并带上模型

三个下载源在国内实测均已失效（官方源仅 0.15~0.40 MB/s，两个镜像 404 / 403），
**单 exe 首次联网下载模型基本无法完成**。正确做法是把模型与 exe 放在一起：

```
键译.exe
models\
├── packages\zh_en\    ← 中→英，必需（83 MB）
├── packages\en_ja\    ← 中→日，按需（129 MB）
└── cache\             ← 下载缓存，可选（删了不影响运行）
```

**唯一硬性约束**：路径必须为**纯英文**（分词器无法打开含中文的路径）。
若放在中文目录，程序会自动把模型改放到 `%LOCALAPPDATA%\BoardTrans`，功能不受影响。

## 已知限制

1. 中→日质量弱于中→英（经英文中转所致），正式文本建议核对
2. 管理员权限窗口需本程序也以管理员运行才能取词（Windows UIPI 安全机制）
3. `paste` 模式下译文会进剪贴板历史（Win+V），改 `type` 模式可避免
4. 自动取词范围是「光标所在的整段」（向上扩到空行为止，最多 25 行）；
   想只翻一句请把 `capture_mode` 设为 `line`，想完全自己掌控就先手动选中
5. 源码运行需 Python 带 tkinter：官方安装包默认自带，精简版会缺（仅影响设置界面）
6. Win 键组合无法在窗口内录制，需在 `config.json` 手写 `"hotkey": "windows+j"`
7. 钩子类软件的快捷键冲突检测不到；保存后按键无反应时，换一个更复杂的组合
